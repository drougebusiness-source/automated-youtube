Channel Uploader ("the tool") is a private application operated by Rouge Ventures LLC ("we", "us"). This policy explains what data the tool accesses and how it is handled.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy.

What data the tool accesses

The tool signs in with Google OAuth using only our own Google account, and requests permission to upload videos and manage videos, thumbnails and playlists on our own YouTube channel. It does not access, collect, store, or share any data about other YouTube users or channels. It does not use cookies or tracking on this website.

How data is used and stored

The only data stored is the OAuth sign-in token, kept privately and encrypted by us, and a small log of which of our own videos were uploaded and when. This data is used only to upload our videos. It is never sold, shared with third parties, or used for advertising.

Data retention and deletion

  • Generated video files are deleted automatically after they are uploaded.
  • The OAuth token is kept only while the tool is in use, and is deleted within 7 days of us stopping use of the tool or on request.
  • Access can be revoked at any time on the Google security settings page (Third-party apps & services). Revoking access immediately stops the tool from using the account.
  • To request deletion of any stored data, email drouge.business@gmail.com. We will delete it within 7 days.

Changes

If this policy changes, we will update this page and the date above.
